Cloud Computing

Cloud computing has become an essential tool for researchers and data scientists when local computing resources are insufficient or inconvenient. This section explores the concept of cloud computing, its applications, and the resources available to researchers.

Understanding Cloud Computing​

Cloud computing provides on-demand access to a shared pool of configurable computing resources. These resources can include networks, servers, storage, applications, and services, which can be rapidly provisioned and released with minimal management effort.

The image above illustrates some of the major commercial cloud computing providers and their offerings. These services allow researchers to scale their computational power as needed, without the need for significant upfront investment in hardware.

National Supercomputing Resources​

For researchers in the Netherlands, the Snellius supercomputer offers another powerful option for high-performance computing.

Snellius OnDemand​

Snellius provides an OnDemand interface, making it easier for researchers to access and manage their computational resources.

These interfaces allow researchers to submit jobs, monitor progress, and manage their allocated resources efficiently.

Accessing Snellius​

Researchers can apply for small compute grants on Snellius, which can provide up to 1 million System Billing Units (SBUs). This translates to approximately 5,200 hours of H100 GPU time, offering substantial computational power for research projects.

The application process involves collaboration with a thesis supervisor and typically takes about two weeks. Snellius provides extensive documentation to help researchers make the most of its resources.

Choosing the Right Resources​

When planning a research project that requires cloud or high-performance computing, it's crucial to understand the specific needs of your task. Let's explore some common scenarios:

Working with Large Datasets​

For projects involving large datasets, such as extensive market research data exceeding 4GB, RAM becomes a critical factor. A general rule of thumb is to have 2.5 times the dataset size in available RAM. When working with datasets that push the limits of available memory, consider implementing batching techniques to process data in smaller chunks.

Using efficient data formats like .parquet can also significantly improve performance and reduce memory requirements. These formats allow for faster I/O operations and more efficient storage.

Handling Gigantic Datasets​

When dealing with truly massive datasets, such as those encountered in high-frequency trading (1TB+), it becomes impossible to load all data into memory at once. In these cases, batching is not just an optimization but a necessity.

Efficient I/O operations become crucial when working with such large datasets. Strategies like memory-mapped files or specialized big data processing frameworks may be necessary to handle the data effectively.

Deep Learning Projects​

Deep learning tasks, particularly those involving large language models, often benefit greatly from GPU acceleration. However, GPU memory can quickly become a bottleneck, especially when fine-tuning large models.

To optimize GPU usage, consider techniques such as loading models in lower precision (e.g., 16-bit floating-point) or using specialized methods like parameter-efficient fine-tuning. These approaches can significantly reduce memory requirements while maintaining model performance.

Parallel Processing Tasks​

Some research tasks, like transforming raw data into structured tables, can benefit from parallel processing across multiple CPUs or even multiple nodes in a cluster. In these scenarios, understanding concepts like threading and Message Passing Interface (MPI) becomes important.

Efficient I/O operations are again crucial, as the speed of data transfer between nodes can often be a limiting factor in overall performance.

By carefully considering the nature of your research task and the available computing resources, you can choose the most appropriate and cost-effective solution, whether that's a commercial cloud provider, a national supercomputing facility, or a combination of resources.
