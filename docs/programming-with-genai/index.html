👤 Programming with GenAI

Interacting with Computers​

When working with computers for extended periods, we often face several common challenges. Fatigue can set in, making it difficult to maintain focus on the correct files or code sections. Mental overwhelm is another issue, especially when dealing with complex programming tasks that increase cognitive load. And finally, impatience often emerges when waiting for processes to complete without clear indicators of progress.

To address these challenges, consider implementing some practical strategies. When feeling tired, double-check that you're editing the right file and follow the advice to sketch your ideas on paper or a whiteboard first before coding. For mental overwhelm, use a clean, minimal editor that reduces visual distractions and friction. And when impatience strikes, implement progress bars, logs, and print statements to provide visibility into your program's execution—though remember that not all computational problems scale linearly with time.

Programming with GenAI Tools​

The Rise of AI-Assisted Coding​

According to recent surveys, approximately 90.5% of developers now use Large Language Models (LLMs) in their coding workflow. This represents a significant shift in how programming is approached and executed.

However, there's an important distinction between using AI tools effectively and what some call "vibe coding"—a more passive approach where developers rely too heavily on AI suggestions without critical engagement.

I've been programming with GitHub Copilot for ~1 year and it has profoundly changed my relationship to coding. I now mostly vibe check its suggestions and gently shepherd it in the right direction. It's a weirdly right-brained process. I'm not going back.

— Andrej Karpathy (@karpathy) January 24, 2023

Effective Use of GitHub Copilot and Cursor​

When working with AI coding assistants like GitHub Copilot or Cursor, establishing clear communication with the tool can significantly improve results. One effective practice is to create system prompts that guide the AI's behavior.

A simple way to implement this is by adding a comment like "assisted by Cursor AI" around areas where you want AI assistance. This helps both the AI tool and human collaborators understand which parts of the code were developed with AI assistance.

# assisted by Cursor AI
print(1 + 1)

Maximizing AI Coding Assistance​

For optimal results with AI coding tools, two key factors should be considered:

Context is Key: The AI needs sufficient context to provide relevant suggestions. This includes the current file content, related files in your project, documentation, and other contextual information that helps the AI understand your specific programming environment and goals.

Different Interaction Modes: Most advanced coding assistants offer various interaction modes. You can use chat interfaces for general questions, edit mode for direct code modifications, or even agentic modes where the AI takes more initiative in solving problems. Learning when to use each mode can significantly enhance your productivity.

tip

Remember that you will likely review more code than you write, especially when working with AI assistants. Developing strong code review skills becomes even more important in this workflow.

Comparing Coding Approaches​

When working with AI coding assistants, it's worth considering whether writing code and fixing bugs require the same approach, and whether human-first or AI-first workflows are more effective.

Human-First vs. AI-First Workflows​

In a human-first approach (Human → Copilot), you start by thinking through the problem and then use AI to help implement your solution. This approach encourages deeper thinking and better-structured code that follows your mental model. However, it can sometimes limit creativity and may not leverage the AI's knowledge of best practices.

Conversely, in an AI-first approach (Copilot → Human), you let the AI generate initial code that you then review and modify. This can expose you to new patterns and solutions you might not have considered, and it provides a scaffold to build upon. The downside is the increased cognitive load required to understand the generated code and the risk of overlooking logical flaws or hallucinations that might cause problems later.

Cloud Computing for Advanced Projects​

When your laptop's computing power becomes insufficient or inconvenient for your programming tasks, cloud computing offers a scalable alternative. Major commercial providers like Google Cloud Platform (GCP), Amazon Web Services (AWS), and Microsoft Azure provide a wide range of computing resources on demand.

Understanding Cloud Computing Costs​

Cloud computing costs can vary significantly based on your requirements. For instance, running specialized hardware like NVIDIA H100 GPUs for machine learning can be particularly expensive. When planning a project that requires substantial computing resources, it's essential to calculate these costs in advance.

Fortunately for researchers, many cloud providers offer academic programs with significant discounts or grants. Programs like Google Cloud for Researchers and Amazon Research Awards can provide access to computing resources that would otherwise be prohibitively expensive.

Snellius: The National Supercomputer​

For researchers in the Netherlands, Snellius offers an alternative to commercial cloud providers. As the national supercomputer, it provides high-performance computing resources specifically designed for research applications.

Accessing Snellius​

Snellius offers an OnDemand platform that makes it easier to access its computing resources:

Researchers can apply for Small Compute Grants through NWO, which provide up to 1 million SBUs (equivalent to about 5,200 hours of H100 GPU time). Applications typically take about two weeks and require supervisor involvement. Snellius provides extensive documentation to help users get started.

Using Snellius​

There are two main ways to use Snellius:

  1. OpenOnDemand platform: Access through the website, log in with SURF credentials, choose your preferred IDE (JupyterLab, RStudio, VS Code), and select the resources you need.

  2. SSH access: Use your own IDE (like VS Code with GitHub Copilot or Cursor), connect to Snellius via SSH, start a compute job, and then connect to that job through your IDE.

Choosing the Right Computing Resources​

When planning a computational project, selecting appropriate resources depends on your specific needs:

For Large Datasets​

When working with datasets in the multi-gigabyte range, RAM becomes crucial. You'll typically need about 2.5 times the data size in available memory. If your dataset exceeds available RAM, consider implementing batching strategies and using efficient file formats like Parquet that support partial loading. Market research projects with 4GB+ datasets often fall into this category.

For Gigantic Datasets​

With truly massive datasets (1TB+), loading everything into memory becomes impossible. In these cases, effective batching strategies are essential, and I/O operations become a critical bottleneck. High-frequency trading applications often deal with datasets of this magnitude.

For Deep Learning Projects​

Deep learning tasks, especially those involving large models, benefit tremendously from GPU acceleration. However, GPU memory often becomes the primary bottleneck. Consider loading models in lower precision formats (like FP16 instead of FP32) to reduce memory requirements. Fine-tuning large language models typically requires at least a few hundred GPU hours.

For Highly Parallel Tasks​

Some computational problems can be broken down into independent tasks that can run simultaneously. For these workloads, access to multiple CPUs or compute nodes becomes important. Threading and Message Passing Interface (MPI) implementations help manage these parallel processes, with I/O operations often becoming the limiting factor. Data preprocessing pipelines that transform raw data into structured tables often benefit from this approach.
